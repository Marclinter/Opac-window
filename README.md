# Opac-window
Es un proyecto que hice de carácter autodidacta, con uso de herramientas, es un proyecto que se centra en crear una aplicacion de cifrado local de archivos que a su vez puede modificar estos y previsualizarlos, permite guardar tus archivos en diferentes cajas fuertes y ponerle pings a estas, permite tener varios usuarios, cifra localmente tus archivos y puedes decidir si al abrir la caja fuerte hacer que todos se desencripten de golpe o solo el que selecciones (ideal), permite activar un modo con administrador para que no se puedan borrar tus archivos (opac guard), No soy un profesional, el código no es perfecto y no debes considerar que ofrece una protección mas allá de algo simple o mediano acorde a tus necesidades, aunque los test pasan sadisfactoriamente, es una alfa, aunque pueda salir como beta, esta en fase de desarrollo y sois libres de tomarlo de base para vuestros proyectos dando crédito o de mejorar este existente, me daria un gran honor, no quiero que lo uséis de forma ilegal para ocultar material pirata o pruebas de algo o similar, es un software para la gente que tiene alto riesgo de que le revisen la PC o no quiere que un haker pueda acceder a todo el contenido de esta muy facilmente, y si logro sacar una version en linux (o la hace alguien), podra tambien servir para servidores, es todavia un proyecto algo rudimentario, pero funcional, y por eso lo publico aqui

This is a self-taught project I developed using various tools. It focuses on creating an application for local file encryption, which also allows for file modification and previewing. You can store files in different "vaults"—each protected by a PIN—and support multiple users. Files are encrypted locally; when opening a vault, you can choose to decrypt everything at once or just the specific file you select (a very useful feature). There is also an "administrator" mode (or "opac guard") that prevents files from being deleted. I am not a professional, and the code is not perfect; please do not assume it offers more than basic to moderate protection, depending on your specific needs. Although it passes all tests, it is currently in an alpha stage—potentially approaching a beta—and is still under active development. You are free to use this as a foundation for your own projects (provided you give credit) or to improve upon the existing code; I would be honored if you did. Please do not use this software for illegal purposes, such as hiding pirated material or concealing evidence. It is intended for individuals at high risk of having their PC inspected, or for those who want to prevent a hacker from easily accessing all the data on their computer. If I manage to release a Linux version (or if someone else creates one), it could also be used for servers. It is still a somewhat rudimentary project, but it is functional—which is why I am sharing it here.
